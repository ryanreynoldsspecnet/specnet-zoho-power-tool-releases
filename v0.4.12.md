# Specnet Zoho Power Tool 0.4.12

- Distinguish network timeouts and interrupted requests from cancellation requested by the user. Include the failed operation and underlying error details in the log.
- Stop weekly debit-order file generation if prior-batch retry checks fail or are cancelled, so incomplete verification cannot continue into an export.
- Preserve existing invoice selection rules, receipt allocations, saved batches, settings and cache data.

Validation: Release build passed with no warnings or errors; 13 regression groups passed, including timeout reporting, FNB allocations, duplicate prevention, retry history, voided batches and preservation of saved batches. Tests use synthetic data and make no live Zoho changes.

This update improves failure reporting and safe stopping. It does not make an unstable internet connection reliable or automatically replay payment, invoice or email operations.
